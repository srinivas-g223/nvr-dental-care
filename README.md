# NVR Dental Care

Responsive single-page website for NVR Dental Care.

## Run locally

```powershell
npm run dev
```

The project is static HTML, CSS, and JavaScript. Keep the `assets` folder next to
`index.html`; service photos are stored locally in `assets/`.

## Deploy

The site can be deployed as a static project on Vercel. No build command or
output directory is required.
