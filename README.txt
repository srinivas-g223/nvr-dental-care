NVR Dental Care - single page website

Open index.html in a browser. Keep the assets folder next to index.html.
To replace a photo, overwrite the file in assets/ with the same name.
Phone/WhatsApp: search 918121073917 in index.html to change.

To run locally: npm start (needs Node.js). Or just double-click index.html.
Deploy: drag this folder to Netlify, or run "vercel" inside it. No build step needed.
